# ✨ QR Code Generator

A full-stack web application that generates QR codes from any text or URL.

## 🚀 Features
- Type any text or URL
- Instantly generates a scannable QR code
- Download the QR code as a PNG image

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Axios
- **Backend:** Python, Flask, QRCode, Pillow

## ▶️ How to Run Locally
1. Start Backend: `cd backend && venv\Scripts\python.exe server.py`
2. Start Frontend: `cd frontend && npm run dev`
3. Open `http://localhost:5173`
